١. فكرة المشروع

مركز المعرفة والابتكار STEAM هو منصة إلكترونية تعليمية مؤسسية متكاملة صُمِّمت خصيصاً لمدارس الأرقم، بهدف توحيد إدارة برامج الموهبة والابتكار والذكاء الاصطناعي في مكان واحد على الإنترنت.

المشكلة التي تحلها: كانت إدارة البرامج مشتتة بين ملفات منفصلة ورسائل واتساب وجداول بيانات — المنصة جمعت كل شيء في نظام واحد متكامل يمكن الوصول إليه من أي جهاز.

٣. لغة البرمجة

المنصة مكتوبة بالكامل بلغة TypeScript — وهي نسخة متطورة من JavaScript تضيف أنواع البيانات لتجنب الأخطاء.

  • الواجهة الأمامية (Frontend): React TypeScript Tailwind CSS
  • إطار العمل: Next.js 14 App Router
  • قاعدة البيانات: Firebase Realtime Database localStorage
  • الاستضافة: Vercel Cloud
  • إدارة الكود: GitHub

٦. الميزات التقنية البارزة

  • تصميم RTL عربي كامل — المنصة مصممة من الأساس باللغة العربية
  • متجاوب مع الجوال — تعمل على الجوال والتابلت والكمبيوتر
  • قاعدة بيانات سحابية — Firebase من Google تتزامن بين جميع الأجهزة
  • نشر تلقائي — أي تحديث على GitHub ينعكس فوراً على المنصة
  • مجاناً بالكامل — الاستضافة والقاعدة البيانات بدون أي تكلفة
  • أمان متعدد المستويات — كلمات مرور ورموز تسجيل وصلاحيات مختلفة
  • شعار مدارس الأرقم — مدمج في واجهة المنصة بشكل احترافي

٨. جمل جاهزة للعرض

🎯 الجملة الافتتاحية:

"أنشأت منصة إلكترونية متكاملة لإدارة مركز الموهبة والابتكار STEAM في مدارس الأرقم. المنصة تجمع ٢٥ قسماً في مكان واحد — من إدارة المشاريع والدورات والمسابقات إلى متابعة المنسقين والطلاب، مع قاعدة بيانات سحابية تعمل من أي جهاز."

🔧 إذا سألوا: بأي تقنية بنيتها؟

"المنصة مبنية بإطار عمل Next.js مع React و TypeScript في الواجهة، وTailwind CSS للتصميم، و Firebase من Google كقاعدة بيانات سحابية، وVercel للاستضافة. كل التقنيات المستخدمة مفتوحة المصدر ومجانية."

💡 إذا سألوا: كم استغرق التطوير؟

"المشروع مر بمراحل متعددة من التخطيط والتنفيذ والاختبار، وتم بناؤه بمنهجية Agile — قسم قسم حتى اكتملت المنصة."

🌐 إذا سألوا: أين مستضافة؟

"مستضافة على Vercel — وهي نفس المنصة التي تستضيف كثيراً من تطبيقات الشركات الكبرى. الاستضافة مجانية وتدعم النطاق العالمي."

🔒 إذا سألوا: كيف تحمي البيانات؟

"النظام يعمل بصلاحيات متعددة المستويات — المسؤول يوافق على كل تسجيل قبل منح الدخول. البيانات محفوظة على Firebase من Google التي تلتزم بأعلى معايير الأمان العالمية."
